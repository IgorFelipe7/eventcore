# Security policy

EventCore is a portfolio project with a public demo that contains fictional data only. Please do not run load or exploitation tools against a deployed demo.

If you find a vulnerability — especially in tenant isolation, token verification or idempotency — open a private security advisory on the repository, or contact the author directly. Include the request, the expected and the observed behaviour, and the `x-request-id` if you have one. You will get an answer within a few days.

The threat model, its controls and its known residual risks are in [`docs/threat-model.md`](docs/threat-model.md).
